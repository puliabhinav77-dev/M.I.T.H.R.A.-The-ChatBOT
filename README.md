# M.I.T.H.R.A.-The-ChatBOT
MITHRA:  Is a fully offline chatbot developed in order to provide user-centric conversation with powerful LLM models like mistral and DeepSeek-Coder-V2 by using multiple tech stacks like python,FASTAPI in the backend and HTML, CSS and JavaScript in the frontend. Used AI tools like Claude and ChatGPT to solve critical problems. 
A key highlight of MITHRA is its 100% local inference architecture, ensuring complete data privacy and zero external data transmission. The application supports dynamic model switching, allowing users to seamlessly move between general AI interactions and coding-focused workflows. Its modular FastAPI structure also makes the system highly extensible for future integrations and feature expansion.
